## 1. Anthropic's new Claude Duet app messages you first, and asks before it sends, pays, signs or deletes
**Source:** https://claude.com/resources/articles/claude-duet (primary, Oct 21, 2026)
**Skill used:** ai-post-crafter
**Frame / angle:** Frame: product launch. Angle: stakes-first, focused on the permission design (what it asks about, what it refuses even if you say yes). Frames not taken: capability evaluation (no benchmarks given), safety-research (the post says a fuller safety write-up is still coming).

An assistant that watches your email and calendar all day is making hundreds of small calls about what deserves your attention. Anthropic opened a waitlist on Wednesday for one: Claude Duet.

It's a research preview, US Pro and Max subscribers first, on iOS, Android and claude.ai. Anthropic says it's built around Claude Opus 5.5. Each morning it sends a short brief from your connected apps, checks those accounts every few hours (not constantly, because that would burn through your plan's usage limits), and messages you only when something needs you. It runs on its own virtual machine with a browser, so work continues when your laptop is closed.

The part I read most closely is the permission design. Before it sends a message, makes a payment, signs a document or deletes anything, it shows you what it's about to do and waits. Trading securities and moving money between your accounts are off-limits even if you approve. A new classifier is meant to refuse sharing the strictest tier of data, such as credit card numbers and government ID, while health and personal finance details go out only if you explicitly tell it to.

What this shows is the design Anthropic chose. What it doesn't show is how well it works: the post cites red-teaming and an outside penetration test but gives no numbers, and says more safety details are coming in the next few days. I haven't used it; I'm on no waitlist yet. My read: the interesting test is how often it asks. Too rarely is a risk. Too often and the approvals become a rubber stamp.

## 2. Anthropic hands the Agent Skills standard to the Linux Foundation, and the security guidance is still only a roadmap item
**Source:** https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation (primary, Oct 22, 2026)
**Skill used:** ai-post-crafter
**Frame / angle:** Frame: industry news / dev tooling. Angle: frame-shift. Coverage reads this as a governance gesture; the more useful detail is that a "skill" is code and instructions people install by the million, and security guidance is only now being proposed. Frames not taken: technique explainer, competitive story.

A "skill" for an AI agent is just a folder with a text file in it. That folder is now the closest thing the agent world has to a shared plug-in format, and on Thursday Anthropic gave it away.

Per Anthropic's post, Agent Skills (a SKILL.md file that teaches an agent one task, plus any scripts and reference material) has been integrated by more than 70 platforms, including ChatGPT, Cursor, GitHub Copilot and VS Code. Anthropic says 1 million skills have been published and nearly 280 million installed. Those are the company's own figures. It's donating the name, logo, GitHub organization and the agentskills.io domain to the Agentic AI Foundation, a Linux Foundation project it co-founded with Block and OpenAI, which already hosts Model Context Protocol (MCP). Maintainers from Anthropic, Google, OpenAI and others will serve as individuals.

The detail I'd underline is in the roadmap: versioned releases, a formal proposal process, and "security guidance for people who write and install skills." Because a skill can bundle scripts, installing one is closer to installing software than to saving a note. At 280 million installs, guidance that is still being proposed is the gap worth watching. That's my inference from the post, not something it says.

To be fair, neutral governance is how MCP got broad adoption, and this follows the same playbook. Whether it holds the same pull for a format Anthropic already controlled is something I can't tell from here.
